LitMetrics — это инструмент на Python для автоматического извлечения, обработки и сопоставительного лексического анализа литературных произведений из веб-источников.
Программа парсит текст книг, проводит морфологический анализ, очищает данные от стоп-слов и визуализирует наиболее частотные слова с помощью графиков и облаков слов.

## Особенности

* **Веб-скрейпинг:** Автоматическое извлечение основного текста произведения по URL.
* **NLP-обработка:** Токенизация и лемматизация текста с использованием `pymorphy3` и `nltk`.
* **Частотный анализ:** Подсчет статистики уникальных слов и вычисление лексического разнообразия текста.
* **Сопоставительный анализ:** Выявление общих частотных слов для нескольких произведений и поиск уникальных маркеров стиля автора.
* **Визуализация:** Генерация информативных облаков слов и сравнительных столбчатых диаграмм с помощью `matplotlib`.

## Использование

1. Скачать файл с репозитория.
2. Открыть файл LitMetrics.py и внести ссылки на книги которые требуется проанализировать (желательно с того же источника azbyka.ru).
3. Запустить файл LitMetrics.

Пример облак слов и сравнительной диаграммы находится в папке result.
